## USAGE GUIDE

### For Mockups/Prototypes
- Use produk 1-2 as "Unggulan" (featured) di beranda
- Use produk 3-10 as regular grid items
- Use produk 11-20 for katalog pagination

### For Testing
- Customer 1 (Budi) for main testing flow
- Customer 2 (Siti) for multi-address testing
- Pesanan 1 for "completed" view
- Pesanan 2 for "in progress" view
- Pesanan 3 for "pending payment" flow

### For Screenshots/Demo
- Use realistic data (not "test" or "dummy")
- Show varied states (different statuses, empty vs filled)
- Show mobile + desktop in mockups
